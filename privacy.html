데이터 처리 안내

이 문서는 현재 구현된 개인용 업무 자동화의 데이터 흐름을 설명합니다. 고객에게 적용할 개인정보처리방침과 동의 문구는 업무 운영 기준에 맞춰 별도로 확정해야 합니다.

접근하는 정보와 목적

등록된 폼의 고객명·전화번호·현장 주소·문의일·희망 시공일·담당자·문의상태·주공종·동의 상태·업무 메모를 읽어 소유자의 업무용 시트에 저장합니다. API 요청 대기열·처리 결과·변경이력은 검증, 중복 방지, 결과 확인, 복구를 위해 사용합니다.

Google 권한과 실제 처리 범위

Google 인증은 Drive·Sheets·Forms 및 Apps Script 실행 관련 권한을 요청할 수 있습니다. 해당 권한 자체는 계정의 여러 파일·폼에 접근할 수 있는 범위입니다. 구현 코드는 지정된 업무용 파일과 등록된 폼을 대상으로 자동 처리하도록 제한합니다. 시험 데이터는 별도 시험 사본에서 처리합니다.

저장 위치와 보안

폼 응답은 Google Forms에, 업무 원장·요청 대기열·변경이력은 소유자의 Google 시트에 보관합니다. 응답 누락 복구는 Google 클라우드에서 실행됩니다. 로컬 API 호출용 인증정보는 Windows 현재 사용자 암호화 저장소를 이용해 보관하며 채팅이나 일반 로그에 출력하지 않습니다. 고객 정보가 포함된 원장·대기열·이력에는 별도 접근 관리가 필요합니다.

공유와 외부 서비스

이 앱의 처리 기능은 고객 메시지·견적·결제를 외부로 자동 전송하지 않습니다. Google 서비스 이용에는 Google의 데이터 처리 조건이 적용됩니다. 사용자가 Codex에 자료 조회·작업을 요청하면 해당 서비스의 이용·데이터 처리 조건도 적용됩니다. 이 안내 페이지에는 고객 원장 데이터나 인증정보를 포함하지 않습니다.

보유·삭제와 권한 철회

보유 기간과 삭제·백업 정책은 소유자가 확정할 사항입니다. 업무 원장을 삭제해도 Forms 응답·대기열·변경이력·별도 백업에 정보가 남을 수 있으므로 관련 저장소를 함께 검토해야 합니다. Google 계정에서 앱 권한을 철회하면 API 연결이 중단될 수 있습니다. 폼 접수·예약 처리를 중지하려면 운영 설정과 트리거도 함께 확인해야 합니다.
